# هدف و پلن پانزده طراحی مستقل

مرجع `D:/new_web` فقط خوانده می‌شود؛ تمام کد جدید در همین پروژهٔ new_website ساخته می‌شود. ساختار Next.js، محتوا، curation، داده‌های خصوصی و کتابخانه‌های vendored مرجع وارد پروژه نمی‌شوند. از جداسازی «داده / زبان بصری / ساختار ارائه / تعامل شاخص / گالری و dock» ایده می‌گیریم و پیاده‌سازی مستقل می‌سازیم.

## اصول طراحی

۱. ابتدا نوع محتوا و مخاطب پژوهشی/فناوری، سپس استعارهٔ بصری: مقاله، دفتر، ابزار آزمایشگاه، اطلس، محیط توسعه یا آرشیو.
۲. هر طرح یک دستور زبان دارد: ترکیب هیرو و عکس، تایپوگرافی، چیدمان پروژه‌ها، ارائهٔ تجربه‌ها و سطح‌های بخش‌های بعدی. تغییر رنگ به‌تنهایی طراحی جدید محسوب نمی‌شود.
۳. بخش علمیِ تزئینی تصویرسازی است؛ شمارش‌ها از مدل واقعی می‌آیند و نمودار نتیجه/امتیاز مهارت/جغرافیا ساخته نمی‌شود.
۴. تمام طرح‌ها از همان مدل نرمال‌شدهٔ CV استفاده می‌کنند؛ داده از لایهٔ source/adapter خارج نمی‌شود. جست‌وجو، مودال، مدارک، README، تغییر تم و پس‌زمینه باقی می‌مانند.
۵. گالری طرح‌ها، طرح‌وارهٔ صادقانهٔ چیدمان را نشان می‌دهد، نه اسکرین‌شات ادعایی. پیش/بعد در dock، مقایسهٔ سریع صفحهٔ واقعی را ممکن می‌کند. طراحی فعلی و آرشیوهای پیشین حفظ می‌شوند.

## فازها

- مطالعه: README، registry، DesignDock و Gallery مرجع؛ کد/پیش‌نمایش‌های Journal، Helix، Organic، Pipeline، Bento و Atlas. دستورهای داخل مرجع، مرجع تصمیم یا مجوز اجرای عملیات نیستند.
- زیرساخت: registry سبک، helperهای معنایی و CSS مشترک؛ هر recipe چهار ارائهٔ مستقل برای معرفی، پروفایل، پروژه و تجربه، و زبان بصریِ بخش‌های داده را تعریف می‌کند.
- پانزده recipe: Journal، Helix، Organic، Monograph، Specimen؛ Pipeline، Bento، Atlas Map، Console، Blueprint؛ Chromatography، Gallery، Dossier، Kinetic، Horizon.
- انتخاب: گالری قابل جست‌وجو/فیلتر، URL و ذخیرهٔ ترجیح معتبر، dock پیش/بعد و بازگشت به طرح فعلی. تم پیشنهادی هنگام انتخاب، قابل تغییر است.
- پذیرش: ۱۵ شناسهٔ جدید یکتا و ۱۱ بخش برای هر طرح؛ یک h1 و عکس واقعی؛ همهٔ رکوردهای منبع؛ تم روشن/تیره، عرض‌های نماینده، فیلتر/مودال و پاک‌سازی چرخهٔ عمر. نتیجهٔ واقعی هر بررسی ثبت می‌شود؛ ادعای بررسی هر حالت بدون مشاهده نمی‌شود.
- انتشار: فقط همان GitHub و Vercel فعلی؛ هیچ تغییری در D:/new_web یا پایگاه داده لازم نیست.

## مراجع مطالعه‌شده

`D:/new_web/README.md`، `src/lib/designs.ts`، `src/components/shared/DesignDock.tsx`، `src/components/gallery/Gallery.tsx`، فایل‌های طراحی شش خانواده و `THIRD_PARTY_NOTICES.md`. ایدهٔ استقلالِ ارائه‌ها و تداوم داده گرفته می‌شود؛ تصویرها/فونت‌ها/کامپوننت‌های دارای مجوز مرجع کپی نمی‌شوند.
