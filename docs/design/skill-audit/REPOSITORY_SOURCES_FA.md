# ممیزی کامل منابع مهارت طراحی و موشن

هر پنج مخزن درخواستی جداگانه و درخت کامل آن‌ها بررسی شد. فایل‌های مهارت و پرامپت با نسخهٔ ثابت دریافت شدند؛ همهٔ بدنه‌ها از دیسک خوانده و تمام خطوط برای دستورها، وابستگی‌ها، شبکه، اعتبارنامه و نوشتن/حذف فایل بررسی شدند. برای اقدامات حساس، کد واقعی نیز بازبینی شد. این ممیزی اثبات بی‌نقص‌بودن تمام برنامه‌های شخص ثالث نیست. هیچ کد دانلودشده، hook، نصب بسته یا درخواست تولید رسانه اجرا نشده است.

نتیجه: **۷۰۸ مسیر واقعی SKILL.md**، **۵۵۳ بدنهٔ متمایز** و **۴۸ فایل پرامپت تخت**. پس از حذف نسخه‌های توزیعی تکراری و ۱۹ fixture/مثال آموزشی، **۴۸۰ ریشهٔ یکتا** برای کپی وجود دارد: ۴۰۱ از OpenDesign، ۲۳ از ClaudeDesignSkills و ۵۶ از بسته‌های iart. از این ۴۸۰ مورد، ۸۴ مورد صرفاً اشاره‌گر کاتالوگ‌اند؛ نصب آن‌ها ابزار یا قابلیت upstream را نصب نمی‌کند. ۱۴ مورد نام/frontmatter لازم Codex را ندارند و به ورودی تطبیقی نیاز دارند.

این شمارش با تعداد نصب نهایی یکسان نیست: هماهنگ‌کننده ۳۱ ورودی تطبیقی برای ۱۷ پرامپت OpenCowork و ۱۴ رویهٔ Codex در Trystan، و ۱۶ مهارت مستقل Emil از ممیزی MOTION_WEB_SOURCES را نیز خواسته است؛ وضعیت نصب واقعی و هش‌ها در INSTALLATION.json ثبت می‌شود.

تمام ۷۵۶ بدنه با SHA-1 استاندارد blob گیت و SHA-256 تطبیق داده شد. منبع JSON کنار این سند، تک‌تک ۷۰۸ occurrence، مسیرهای alias، نام، توضیح، مجوز، وابستگی، شاهد خطر، ref و دستور installer را نگه می‌دارد.

## تشخیص نمونه، نسخهٔ تکراری و قالب واقعی

پوشه‌های `tests/fixtures`، دو sentinel انجمن و مثال‌های نگارش در `plugins/spec/examples` و `docs/examples` در فهرست ثبت شده‌اند ولی نصب نمی‌شوند. در مقابل، `plugins/_official/examples` مجموعهٔ قالب‌های واقعی runtime است؛ نام «examples» به‌تنهایی دلیل حذف آن نیست. ریشهٔ کامل هر نام انتخاب شده و تمام aliasها، حتی با بدنهٔ متفاوت، حفظ شده‌اند. انتخاب ریشه بر اساس نام اعلامی در همان مخزن است؛ منابع متفاوت جدا می‌مانند. دو نسخهٔ lower-thirds در بسته‌های iart نیز مستقل نگه داشته شده‌اند.

## نگاشت به بازطراحی سایت

تایپوگرافی، ریتم، فاصله و ترکیب‌بندی از راهنماهای بصری؛ بازخورد، خروج، وقفه و حرکت اسکرول از مهارت‌های موشن رابط؛ reduced-motion و کیبورد از منابع دسترس‌پذیری؛ و گرافیک سه‌بعدی/ویدئو فقط برای بخش واقعاً لازم استفاده می‌شوند. کپی مهارت هیچ کتابخانه‌ای وارد bundle مرورگر نمی‌کند. دستورهای vendor برای تبدیل پروژه به React، نوشتن AGENTS، ایجاد سؤال اجباری، تعداد ثابت خروجی یا آپلود رسانه جایگزین درخواست فعلی و قرارداد پروژه نیستند.

## نصب و مجوز

نصب از helper رسمی skill-installer انجام می‌شود: آماده‌سازی هر مخزن در commit ثابت فقط یک‌بار، سپس اعتبارسنجی مسیر/نام/skill و کپی منابع هر ریشه. مقصد فقط `.agents/skills` همین سایت است؛ پوشه‌های موجود بازنویسی نمی‌شوند. نسخهٔ اصلی SKILL.md، بدنهٔ دستورها، همراه‌ها و مجوزهای محلی/ریشه حفظ می‌شوند؛ نام و frontmatter نصب‌شده با منشأ روشن تطبیق داده می‌شود. تشخیص خودکار مهارت در نوبت بعدی Codex باید از ثبت واقعی نصب جدا گزارش شود.

مجوز ریشهٔ OpenDesign، Apache-2.0 است و برخی زیرپوشه‌ها مجوز مستقل دارند. سایر منابع اصلی و ۱۸ بستهٔ iart در بررسی فایل LICENSE، MIT بودند؛ بستهٔ generative-illustration-skills هیچ فایل مجوز یا اظهار مجوز در README ندارد؛ skill-creator در مجموعهٔ freshtechbro مجوز محلی Apache دارد. برند، تصویر، فونت، موسیقی نمونه و upstream خارجی می‌تواند شرایط جدا داشته باشد؛ notice همراه آن‌ها حذف نمی‌شود.

در GitHub REST عمومی هنگام گسترش بسته‌ها خطای واقعی HTTP 403 rate limit رخ داد؛ خواندن native GitHub ادامه یافت و هر ۱۹ بسته دریافت شد. خطای transport در پاسخ بسیار بزرگ درخت OpenDesign با خواندن عمومی درخت کامل جبران شد. هیچ منبعی صرفاً به‌دلیل «غیرقابل اعتماد» رد نشد.

## منبع تکمیلی Impeccable از دایرکتوری موشن

[pbakaus/impeccable](https://github.com/pbakaus/impeccable) در commit ثابت `9fadc41729c38fd47d7ae622b501558653f9d2e9` با مجوز Apache-2.0 بررسی شد. نسخهٔ فعلی فقط **یک مهارت یکپارچه** دارد؛ ۲۲ نسخهٔ توزیعی و ۴ fixture آزمایشی در درخت دیده شد. `animate` اکنون راهنمای همراه در `reference/animate.md` است، نه یک مهارت native مستقل. کل بستهٔ Codex با این راهنما نصب می‌شود. پس شمار ریشه‌های این ممیزی ۴۸۱ و تعداد نهایی با ۳۱ adapter و ۱۶ مهارت Emil، **۵۲۸** است.

launcher این بسته ممکن است در نخستین اجرا binary نسخه‌دار را در پوشهٔ خانگی دانلود، SHA-256 آن را با manifest بررسی و سپس اجرا کند؛ hook و pin نیز تغییر یکپارچه‌سازی پروژه دارند. این کدها اجرا نشده‌اند و ورودی محلی مستقیماً به playbookها مسیر می‌دهد. فایل LICENSE و NOTICE.md شامل انتساب منابع پلتفرم حفظ می‌شوند.


## نتیجهٔ نصب واقعی

نصب **۵۲۸ پوشهٔ پروژه‌ای** کامل شد: ۴۹۷ ریشهٔ اصلی/کاتالوگ و ۳۱ adapter پرامپت. اعتبارسنجی metadata و هش **۴۱۸۶ فایل** پس از کپی موفق بود. متن اصلی هر ۵۲۸ ورودی بدون تغییر حفظ شده است. یک بستهٔ generative-illustration مجوز مشخصی در مخزن خودش ندارد و این وضعیت صریح ثبت شده است. اجرا و تهیهٔ تصویر/صدا، دانلود binary، hook و نصب dependency انجام نشده است. کش و مهارت‌های حجیم خارج از Git عمومی باقی می‌مانند. جزئیات در [INSTALLATION_FA.md](INSTALLATION_FA.md) و [INSTALLATION.json](INSTALLATION.json) است.
