# نتیجهٔ نصب مهارت‌های طراحی و موشن

نصب محلی **۵۲۸ مهارت/ورودی تطبیقی** در `.agents/skills` همین سایت کامل شد. هر یک از **۲۵ مخزن در commit ثابت فقط یک‌بار** با helper رسمی آماده شد؛ سپس اعتبارسنجی مسیر، نام، مهارت و کپی رسمی انجام شد. پوشهٔ نامرتبط موجودی بازنویسی نشد.

ترکیب: ۴۰۱ OpenDesign، ۲۳ ClaudeDesignSkills، ۵۶ از ۱۹ بستهٔ iart، ۱۷ adapter برای OpenCowork، ۱۴ adapter برای رویه‌های Codex در Trystan، ۱۶ مهارت Emil و یک بستهٔ یکپارچهٔ Impeccable با راهنمای animate. ۸۴ ورودی OpenDesign صرفاً کاتالوگ‌اند و قابلیت upstream نصب نکرده‌اند.

اصل تمام ۵۲۸ ورودی به‌صورت byte-for-byte در `references/UPSTREAM_SKILL.md` حفظ شده است. بدنه و همراه‌های native، دارایی‌های بسته، مجوزهای محلی و noticeهای ریشه حفظ شدند. نام/frontmatter برای سازگاری و جلوگیری از برخورد نام تطبیق یافته است؛ ۱۴ منبع فاقد metadata و ۳۱ پرامپت تخت، wrapper شفاف دارند. Impeccable نیز wrapper دارد تا استفاده از راهنما به اجرای launcher وابسته نباشد. سیاست explicit-only چهار ورودی upstream حفظ شد.

اعتبارسنجی نهایی: **۴۱۸۶ فایل** با SHA-256 بازخوانی شد؛ حجم منابع و ورودی‌ها **۱۲۷٬۰۴۰٬۲۸۶ بایت، حدود ۱۲۱٫۲ MiB** است. نام‌ها یکتا و حداکثر ۶۳ کاراکترند. منطق بدون تغییر validator رسمی skill-creator با parser امن ruamel.yaml موجود در سیستم اجرا شد؛ PyYAML در این interpreter موجود نبود و بسته‌ای نصب نشد. این بررسی، اعتبارسنجی metadata و تمامیت فایل است؛ کیفیت رفتاری و سرعت رندر را تضمین نمی‌کند.

کد vendor، helper تولید رسانه، برنامهٔ نصب vendor، binary Impeccable، hook، npm/pip یا provider اجرا نشده است. ریشه/پیکربندی سراسری Codex و bundle مرورگر تغییر نکرده‌اند. `.agents/skills/` با exclude محلی Git نادیده گرفته شده و منابع حجیم برای commit نیستند؛ ممیزی، manifest و helper بازتولید در اسناد قرار دارند.

یک استثنای دقیق مجوز: `iart-ai/generative-illustration-skills` در درخت کامل نسخهٔ ثابت، LICENSE/COPYING/NOTICE و اظهار مجوز در README ندارد. آن را MIT برچسب نزده‌ایم؛ README و یادداشت وضعیت مجوز حفظ شده‌اند. وابستگی تولید رسانه به OpenRouter و گزینه‌های Replicate/Gemini فقط مرجع مشروط است.

تشخیص خودکار از چت/پوشهٔ والد فعلی مشاهده و تأیید نشده است. فایل‌ها در پروژهٔ تو در توی `apps/new_website` هستند؛ refresh در نوبت بعدیِ محدود به همین پروژه باید از نصب واقعی فایل جدا گزارش شود. مسیر و نام دقیق هر ورودی در manifest موجود است.

## کاربرد هر مهارت در سایت

برای تک‌تک ۵۲۸ ورودی، `website_usage` شامل وضعیت کاربرد، بخش‌های پیشنهادی و دلیل N/A است. راهنماهای host-specific بدون OpenDesign/OD CLI، workflowهای native/Swift و قیمت‌گذاری، تولید فیلم/۳بعدی نامرتبط و اشاره‌گرهای کاتالوگ، به‌طور خودکار به کد سایت تبدیل نمی‌شوند.

## بررسی مجدد نصب

```powershell
python -X utf8 docs/design/skill-audit/install_project_skills.py --verify-only
```

این فرمان دانلود یا نصب مجدد package و اجرای vendor ندارد. manifest منشأ و وضعیت را تازه و هش فایل‌های نصب‌شده را دوباره بررسی می‌کند. کپی تازه فقط با `--execute` و manifest نسخه‌ثابت انجام می‌شود؛ برخورد با پوشهٔ موجود به‌جای بازنویسی متوقف می‌شود.

نام، منبع، نسخه، وضعیت، هش ورودی و اصل آن، فاز/بخش کاربرد و دلیل N/A برای هر مهارت در [INSTALLATION.json](INSTALLATION.json) آمده است. ledger کامل هش تک‌تک ۴۱۸۶ فایل در `skill_sources_20261103/INSTALLATION_FULL.json` خارج از Git عمومی نگهداری می‌شود؛ helper برای بررسی دوباره از همان ledger استفاده می‌کند. ممیزی همهٔ occurrenceها، aliasها و دستورهای حساس در [REPOSITORY_SOURCES.json](REPOSITORY_SOURCES.json) قرار دارد.

## اصلاح نگاشت کاربرد

نگاشت هر ۵۶ مهارت iart و ۲۳ مهارت ClaudeDesignSkills جداگانه از هدف واقعی آن بازنویسی شد. این‌ها توصیهٔ قابل بررسی‌اند، نه ادعای استفاده یا نصب runtime. درخواست صریح سه‌بعدی/سینمایی حفظ شده است؛ projection محدود SVG انتخاب پیاده‌سازی فعلی است. صدا، تدوین ضرب‌آهنگ و lower-thirds برای خروجی ویدئویی‌اند؛ جهت هنری، رنگ و ترکیب شات اصول مستقیم طراحی‌اند. هیچ فایل نصب‌شده یا رکورد هش تغییر نکرد.
