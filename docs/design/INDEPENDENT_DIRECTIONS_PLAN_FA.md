# پانزده آرت‌دایرکشن مستقل — قرارداد اجرا

این مأموریت مجموعه‌ای تازه می‌سازد. ۱۵ مطالعهٔ قبلی، unified، آرشیو ۲۰ هیرو و داده/قابلیت‌های فعلی حفظ می‌شوند. معیار تفاوت، رندر واقعی هیرو، پروژه و تجربه در دسکتاپ/موبایل است؛ تستِ متفاوت‌بودن نام کلاس‌ها شاهد کیفیت بصری نیست.

## معماری و مرزها

- فقط API/source/adapter و مدل نرمال‌شده، auth، فیلتر، modal، لینک امن و primitives فنی مشترک‌اند. اطلاعات شخصی فقط از مدل است؛ هیچ claim، آمار موفقیت، proficiency یا دادهٔ علمی ساخته نمی‌شود.
- ۱۵ id تازه با `collection: independent` ثبت می‌شوند. فایل‌های قدیمی محفوظ و از انتخاب «مطالعات پیشین» قابل دسترسی می‌مانند.
- هر جهت renderer مستقل برای hero/about/projects/experience و طراحی تمام رکوردها دارد. low-level kit فقط متن امن، hook فیلتر و محتوای رکورد را می‌دهد؛ ترکیب و سیستم بصری را جهت تعیین می‌کند.
- رنگ/تایپ/شکل/فضا در `body[data-design=id]` scope می‌شود. رفتار mobile، تم جایگزین، focus و Still ضروری است. motion باید روی تزئین یا تغییر state هدفمند باشد؛ بدنۀ خواندنی ثابت بماند.
- source و تنظیمات D:/new_web فقط خواندنی‌اند. داده و screenshots واقعی بیرون Git عمومی نگه داشته می‌شوند.

## فازها

1. تعریف ماتریس بالا و جلوگیری از تکرار در کانسپت‌ها.
2. سه مالک مستقل، هرکدام پنج جهت، با helper فنی مشترک و فایل‌های جدا.
3. اتصال registry/gallery و آرشیو؛ حفظ JSON و رفتارهای source-backed.
4. رندر واقعی هر ۱۵ hero و نمونهٔ project/experience، مقایسهٔ کنارهم، نسخۀ structure (رنگ/عکس خنثی)، نقد و اصلاح شباهت/اشکال.
5. بررسی ۵ عرض 320/390/768/1024/1440، تست‌های مرتبط و مرور واقعی مسیر انتخاب/فیلتر/modal/motion.
6. انتشار روی branch و Vercel موجود؛ تطبیق assets و ثبت evidence واقعی production.

پایان بر اساس شواهد مشاهده‌شده است. موارد دیده‌نشده به‌صراحت NOT_TESTED می‌مانند؛ عددِ خودساختهٔ «کیفیت» یا ادعای perfection وجود ندارد.
